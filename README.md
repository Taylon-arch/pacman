# Pacman
Jogo de labirinto inspirado em Pac-Man, desenvolvido em Python com Pygame, com coleta de pontos e fantasmas controlados por uma lógica de perseguição simples.

Como executar
Tenha o Python instalado. Na pasta do repositório, execute:

python -m pip install -r requirements.txt
python pacman.py
No Windows, se o comando python não funcionar, use py no lugar dele.

Use as setas para mudar a direção do Pac-Man. Feche a janela para sair
